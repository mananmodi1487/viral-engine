# Category shifts

Before/after records of repositioning, with dates. This is the directory most likely to be
self-serving, so it is the one with the strictest labelling.

A category shift is when the same artifact is described as a different kind of thing. The
canonical shape:

> Before: "a note-taking app with local storage" — crowded, comparison is by feature list.
> After: "the file you open when you cannot remember what you promised someone" — specific,
> comparison is by job.

## Records

No non-trivial records yet. The two case studies in `../case-studies/` describe shifts made
during development of this project itself, which is the weakest possible evidence: the
author has an interest in the shift having worked.

We are listing that weakness rather than filling the directory with wins.

## What a record must contain

| Field | Why |
|---|---|
| `before` — the original sentence, verbatim | Paraphrasing the old positioning makes the improvement look larger |
| `after` — the new sentence, verbatim | Same reason |
| `date_of_shift` | So the observation window is defined |
| `observed_after` — what changed, with numbers and source | "It felt clearer" is not an observation |
| `confounded_by` | **Mandatory.** What else changed at the same time. This is usually everything. |
| `label` | Almost always `anecdotal` or `self-reported` |

`confounded_by` is mandatory because repositioning is never the only change. If you rewrote
the opening sentence, you also rewrote the title, retimed the launch, and were more excited
when you talked about it. A record that says "category shift → 3x more forwards" without a
`confounded_by` field is a story.

## The uncomfortable question

> How would you know if the repositioning made no difference?

If a record cannot answer that, it does not belong here. It belongs in a blog post, where
the standards are lower and nobody will ask.

## Relevant caveat from the literature

Goel, Watts & Goldstein (2012) found cascade size is heavily influenced by early structural
factors. A repositioning that "worked" may have been a repositioning that happened to be
posted at a different hour to a different first reader. We cannot separate these effects
with the data we have, and neither can most people writing about their own launches.
