# Datasets

Raw inputs that other people can reanalyse. Every file here must be reproducible from the
repository, or accompanied by its provenance.

## The honesty requirement for this directory

Any dataset here must ship with:

1. **Provenance** — where every record came from, and whether consent was obtained.
2. **The selection method** — how records were found, and what was excluded.
3. **A known-bias note** — every dataset has one; a dataset claiming none is hiding it.
4. **A label distribution** — how many `verified` versus `anecdotal` records it contains.
5. **A license** — CC0 or CC BY for data, never a custom restriction.

## What we will not host

- Scraped social profiles, at any level of aggregation that could identify a person.
- Datasets whose consent basis is "it was public". Public is not consent, and this
  repository's whole argument would collapse if it made that exception for its own
  convenience.
- Engagement data from platforms whose terms forbid redistribution.

That last rule means the most useful possible dataset — real broadcast-to-forward conversion
rates — cannot live here. We are saying that before you ask.
