## Rules for this file

- Every source above a token amount is listed, with the amount.
- "Conditions" is mandatory. "None" is a valid entry; leaving it blank is not.
- If a funder asked for anything — a logo, a mention, a feature, a weight — it is written here,
  including the requests that were declined.
- Sponsors get a thank-you line and nothing else. If that ever stops being true, it will be
  visible in this table first.
