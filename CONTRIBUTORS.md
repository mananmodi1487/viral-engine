**This list is nearly empty, and that is the honest state of the project.** One author means
one perspective on every question in these documents, including every question about ethics.
Gaps that a second contributor would catch in an afternoon — the two bindings with no compiler
available, the ten empty evidence directories, the missing accessibility audit — are the ones
a single author could not see.

Add yourself in the PR that earns it. A one-line typo fix counts. So does a rejected PR that
found a real problem with an argument in these documents.

## Reviewers of arguments, not only code

This project makes claims. Some of the most valuable contributions are disagreements with
those claims, recorded in `governance/decisions/` and `evidence/`.

If you think a commitment in `governance/README.md` §1 is wrong, the correct response is an
issue titled with the commitment number, not a silent fork. The fork window is always open
(`governance/README.md` §4) and a fork is a legitimate disagreement. But a fork is also how
commitments quietly disappear, so we ask for the argument in public first — and we will record
it even if we do not accept it.
