# 🧩 Share Structure Canvas

One page. Fill it in before you publish. If a box is empty, the box is your problem.

---

## The share sentence (fill this first)

The exact words a fan uses when forwarding it. Not your caption — *theirs*.

```
"______________________________________________________________"
```

If you can't write this, stop. You have content, not something shareable.

---

## The recipient test

```
I'm sending this to ______________________ (a real kind of person)
because it will help them ______________________ (a real thing)
```

94% of sharers consider how useful content will be to the recipient before sharing (NYT Customer Insight Group, 2011). So: name the recipient or accept a low share rate.

---

## Share mechanisms — pick exactly two

Three or more reads as desperate. Two is a design. One is usually not enough.

| | Mechanism | What it is | Cheap version you can ship this week |
|---|---|---|---|
| ☐ | **Template / fork** | They make their own version | A copy-paste block, not just an output |
| ☐ | **Named pattern** | You give them vocabulary to cite | Name the thing, use it 4+ times |
| ☐ | **Public artifact** | Screenshot-ready proof exists | One card/image with no personal data |
| ☐ | **Completion invite** | Sharing is a required step | "Add yours," a submission thread |
| ☐ | **Tribal marker** | Signals belonging | A stance, a shared enemy, a flag |
| ☐ | **Built-in gift** | Forwarding helps someone specific | A pre-written message, one tap |

Cost to the sharer for #1: ______________________
  → how I lowered it: ______________________

Cost to the sharer for #2: ______________________
  → how I lowered it: ______________________

Rejected mechanism: ______________________
  → why: ______________________
```

## The broadcaster

Popularity tracks the size of the largest single broadcast more than it tracks chain reactions (Goel et al., 2012; 2016). So name a real one.

```
One real person/account/community who could pass this on:
______________________________________________

What they'd need from me to do it:
  - [ ] a clean screenshot
  - [ ] a one-line explanation they can copy
  - [ ] a reason it makes THEM look good
  - [ ] __________________________________

Why they'd bother (their stake, not mine):
______________________________________________
```

```

---

## Pre-publish checklist

- [ ] Could a stranger explain the hook to a friend in one sentence?
- [ ] Is the audience specific enough to name 5 real communities?
- [ ] Does every number have a real source, or an explicit `[placeholder]`?
- [ ] Is there exactly **one** call to action?
- [ ] Would *I* share this from my own account?
- [ ] Have I read the rules of every community I'm posting to?
- [ ] Have I written down the failure condition?

```
This fails if: ______________________________________
```
