# 🎯 Positioning Worksheet

Positioning is not a tagline. It's choosing which category you compete in — and therefore which budget, emotion, and competitor you get. The same product can be boring in one category and urgent in another.

**Time:** 30 minutes. **Output:** one sentence and one honest list of what you gave up.

---

## Step 1 — The obvious category

```
Everyone would file this under: ______________________
```
Label it **CROWDED**. Note the three things you're competing with:

| Competitor | Why they win | Why that's fine |
|---|---|---|
| | | |
| | | |
| | | |

If you can't name three competitors, your category is too vague to be a category. Narrow it.

---

## Step 2 — Three adjacent categories

Same underlying benefit. Different buyer, budget, or emotion.

| # | Category | Who buys it | What they'd pay | Emotion |
|---|---|---|---|---|
| A | | | | |
| B | | | | |
| C | | | | |

**Prompt if you're stuck:** what *else* does your product's outcome get called by a different department? A habit tracker is wellness to one person, career risk to another, and compliance to a third. Same product, three budgets.

---

## Step 3 — Score the candidates

Rate 1–5. The winning frame usually scores 4+ on tension and 3+ on credibility.

| Category | Tension (is there a problem?) | Credibility (can you survive the claim?) | Tribe (is there an in-group?) | Nameable (can you say it out loud?) | **Total /20** |
|---|---|---|---|---|---|
| Obvious | | | | | |
| A | | | | | |
| B | | | | | |
| C | | | | | |

**The trap to avoid:** the highest-tension frame is often the least credible one. If credibility is 1 or 2, the frame becomes the story — and not in the way you want.

---

## Step 4 — Write the sentence

```
It's not ______________________________.

It's ______________________________ — for ______________________________
who ______________________________.
```

**Test each clause:**

- [ ] A stranger could repeat the second half after hearing it once
- [ ] The "who" is specific enough that you can name 5 real communities
- [ ] The claim survives contact with your actual product
- [ ] You'd be comfortable saying it to the smartest person in the room

---

## Step 5 — The honest trade

Every frame costs something. Write down what this one costs you:

```
By choosing "______________________" I give up:

  - The audience who wanted: ______________________
  - The budget from: ______________________
  - The option to also be: ______________________

That's acceptable because: ______________________
```

If you can't fill the last line, you haven't chosen a category — you've written a slogan.

---

## Step 6 — The proof requirement

A frame with no proof is a costume.

```
For this frame to be true, I must show: ______________________

The single most credible piece of evidence I have:
______________________________________________________

If I don't have it, the smallest version I could build this week:
______________________________________________________
```
