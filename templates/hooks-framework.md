# 🎣 The Hook Factory

Copy this into a scratch file. Fill in the blanks. You will produce 12 hooks in about 20 minutes, and 9 of them will be bad. That's the process working.

---

## Step 0 — Lock three inputs

```
AUDIENCE (one sentence, no demographics):
________________________________________________

THE ONE ACTION after they see it:
________________________________________________

THE MOST SURPRISING TRUE THING about this:
________________________________________________
```

If you can't fill in line 3, **stop**. You don't have a hook problem, you have an observation problem. Go find one real, specific, verifiable detail — a number from your own data, a date from your own story, a thing that actually happened. Hooks are compression, not invention.

---

## Step 1 — Two per pattern (fill all 14 blanks)

### 1. Curiosity gap — withhold the mechanism
- The ______ that ______ use to ______
- How ______ gets ______ without ______

### 2. Forbidden insider — violated gatekeeping
- The ______ they don't want you to ______
- Everything ______ knows about ______ that ______ won't tell you

### 3. Paradox — two facts that shouldn't coexist
- I ______ and ______
- The more ______ I did, the ______ I got

### 4. Enemy — name the privately resented thing
- Your ______ is designed to make you ______
- ______ doesn't want you to ______, it wants you to ______

### 5. Receipt — a number someone can verify or envy
- ______ to ______ in ______ (with the timeframe)
- I ______ ______ times. Here's what actually happened.

### 6. Reframe — same fact, new category
- It's not a ______. It's ______.
- You're not ______. You're ______.

### 7. Direct address — recognition in one second
- ______ tabs, ______ deadlines, ______ systems. This is for you.
- If you've ever ______, this is about you.

---

## Step 2 — Kill 9

Score every hook 0–2 on each. Keep the top 3 by total. No ties — if it's a tie, keep the more specific one.

| Hook | Says something about the sharer | Has a specific (number/proper noun/scene) | ≤12 words or a hard-hitting line 2 | **Total /6** |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

**Automatic disqualifiers:**

- ❌ Any of: "powerful," "revolutionary," "game-changing," "unlock," "supercharge," "10x," "seamless," "in today's world"
- ❌ Two claims in one hook
- ❌ Needs a comma-spliced clause to make sense
- ❌ Contains a number you can't source
- ❌ Would embarrass you if the subject of it read it

---

## Step 3 — Write the failure mode for each survivor

Every hook ships with its own failure mode. This is non-negotiable, because the failure mode is what tells you which metric to watch.

```
HOOK 1: ________________________________________
  Pattern: ___________
  Audience: ___________
  Works because: ___________
  Fails if: ___________
  Watch this metric: ___________

HOOK 2: (same block)
HOOK 3: (same block)
```

---

## Step 4 — The out-loud test

Read each surviving hook to a real human, then ask only: **"What do you think this is about?"**

- They describe it correctly and immediately → ship it
- They ask a clarifying question → the hook is ambiguous, not clever
- They say "cool" and nothing else → it's dead, cut it
- They say "wait, is that real?" → you have a winner, keep it

**Do not ask "do you like it?"** Everyone is polite. Nobody is polite about confusion.

---

## Step 5 — Write the line the fan would use

Not your caption. *Their* message when they forward it. If you can't write it in their voice, the hook doesn't give them anything to say — and a share with no sentence attached is a share that doesn't happen.
