# Quizzes

There are none, on purpose.

A quiz measures recall of the module's content. The modules do not contain facts worth recalling;
they contain a method you have to apply to your own artifact. A quiz would let a student pass by
remembering "twenty dimensions" without ever writing a failure condition, which is the opposite of
the point.

## What replaces a quiz

The exercise checkers. `npm run academy -- 09 ./README.md` runs the method against your own work
and fails if the thing the module taught is missing. That is a stronger assessment than recall and
it cannot be gamed by reading the answers, because the answers are your artifact.

## If you are teaching this

The assessment that works in a classroom is peer review with the module 15 protocol, plus the
student's own failure condition written before the result is known. Grade the *quality of the
pre-commitment*, not the outcome — grading the outcome teaches students to pick safe projects.

## If you really want a quiz

Write one yourself, about your own artifact. Then answer it a week later. It will be a better quiz
than anything we could write, and it will measure the only thing worth measuring: whether you still
believe what you wrote.
